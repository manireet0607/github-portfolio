# Manish Kumar - Deployment-Ready Resume Website

Static HTML/CSS/JavaScript website based on the supplied resume.

## Local
Open `index.html` in a browser.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders from this directory.
3. Repository Settings → Pages.
4. Deploy from the `main` branch, root folder.

## AWS S3
Upload the contents to an S3 bucket configured for static website hosting, or preferably serve the bucket through CloudFront.

## Netlify / Vercel
Import the repository and use the project root as the publish directory. No build command is required.

## Important
Replace the placeholder domain in `sitemap.xml` after the website has a real domain.
